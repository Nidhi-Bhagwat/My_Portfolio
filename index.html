MyExpenses — Personal Expense Tracker

Problem
Keeping track of daily expenses manually is tedious and easy to forget.
Built
A desktop app in Python with a clean 3-layer architecture — separating the entry point, UI logic, and database layer — so the code is organized and easy to maintain.
Result
A fully working desktop app where users can log, view, and delete expenses by category and date, all stored locally with no internet needed.
  • Built the full GUI using PyQt6 with 12+ widget classes — dropdowns, date pickers, input fields, and a live-updating expense table.
  • Integrated a local SQLite database with Create, Read, and Delete operations using parameterized queries (prevents SQL injection).
  • Supports 8 expense categories (Food, Travel, Groceries, Clothes, Academics, Entertainment, Stationaries, Other) with date-based sorting.
  • Added input validation, auto-clearing form fields after entry, and a Yes/No confirmation dialog before deleting any record.
